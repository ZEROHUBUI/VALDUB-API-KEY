# VALDUB API KEY

Premium static website that guides users to obtain their own Gemini API Key via the official Google AI Studio path, then return to the VALDUB Android App to paste it.

## Important

- This site does **not** collect, store, or validate any API keys.
- There is no backend and no database.
- All primary CTAs link to the official Google page: https://aistudio.google.com/apikey

## Deploy

Static hosting ready:

- GitHub Pages

- Netlify
- Any static file host
